# Generated Submission Artifacts

- `package_01_metrics.json`: reproducible evaluation on the supplied development package
- `package_02_pages.csv`: required page-level classifications for the unlabeled package
- `package_02_results.json`: page results plus reconstructed document groups
- `package_02_report.html`: standalone, filterable, PII-minimized review report

These artifacts intentionally exclude extracted text and borrower data. Regenerate them using the
commands in the repository README after placing the restricted PDFs under `data/input/`.
